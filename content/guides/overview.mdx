## Core Features

Learn the fundamental building blocks that power every Orcher application.

**[Understanding Orcher](/guides/core/understanding)**
How Orcher's execution model works — journaling, deterministic replay, and durable state.

**[Building Workflows](/guides/core/workflows)**
Define workflows that survive crashes, restarts, and deployments. Compose sequential and parallel steps with automatic checkpointing.

**[Defining Tasks](/guides/core/tasks)**
Write the units of work that workflows execute — with retries, timeouts, and type-safe inputs/outputs.

**[Automatic Journaling](/guides/core/journaling)**

**[Managing State](/guides/core/state-management)**

**[Actors](/guides/core/actors)**

Send and receive events between workflows, implement human-in-the-loop approvals, and coordinate across services.

**[Dealing with Errors](/guides/core/error-handling)**

## Developer Patterns

Proven architectural patterns for common distributed systems challenges.

**[Parent-Child Orchestration](/guides/patterns/parent-child)**
Compose complex workflows from reusable child components. Coordinate distributed services and build hierarchical orchestration trees.

**[Saga & Compensation](/guides/patterns/saga)**
Implement distributed transactions with the saga pattern and compensating actions. Ensure data consistency across multiple services without distributed locks.

**[Fan-Out/Fan-In](/guides/patterns/fan-out-fan-in)**
Split work across multiple parallel operations and aggregate results. Batch processing, multi-service calls, and data aggregation.

**[Long-Running Processes](/guides/patterns/long-running)**
Build workflows that span hours, days, or weeks. Handle human approvals, scheduled operations, and multi-stage business processes.
