The Saga pattern enables you to implement distributed transactions across multiple services without using distributed locks or two-phase commit. A saga is a sequence of local transactions where each step updates a single service. If any step fails, the saga executes compensating transactions to undo the impact of all preceding steps — maintaining eventual consistency across your system. Key concepts include forward recovery (retrying failed steps until they succeed), backward recovery (undoing completed steps on failure), idempotent compensation actions (safe to retry), and eventual consistency (the system reaches a consistent state, though not immediately). Use sagas when you need to coordinate multiple services that each own their own data, handle long-running operations spanning minutes or hours, or avoid distributed locks and two-phase commit protocols.

## Two ways to build a saga

Orcher gives you two ways to run a saga, and you can mix them in the same workflow:

- **The `Saga` helper** — register each step with its compensation as you go, and the helper runs the compensations in reverse order if a later step fails. Best for most sagas.
- **Manual compensation** — write the `try`/`catch` (or `match`) yourself and undo prior steps by hand. Best when you want full control over ordering, partial rollback, or conditional compensation.

Both are built on the same foundation: every action and every compensation is an ordinary task, so each step and each rollback is durable and survives crashes.

## The Saga helper

The helper tracks completed steps and their compensations. There are two ways to register a step, and the difference matters:

- `add_step(action, compensation)` runs the action and registers a compensation that **doesn't** need the action's result.
- `add_compensation(...)` registers a compensation for an action you ran yourself — use it when the compensation needs the action's **output** (a charge id, a booking reference).

Call `commit()` when every step succeeds. On failure, the registered compensations run in reverse order (LIFO). In Python and TypeScript, trigger them from your `except`/`catch` with `saga.compensate()` (it's idempotent); in Rust, the fluent `.execute()` compensates automatically.

```rust
use orcher::prelude::*;
use orcher::workflow::Saga;

#[workflow(name = "book_trip", version = "1.0.0")]
pub async fn book_trip(ctx: WorkflowContext, req: TripRequest) -> Result<Confirmation> {
    let mut saga = Saga::new();

    // Fluent: run the action and register a static compensation. If a later
    // step fails, registered compensations run in reverse order automatically.
    let hotel: Booking = saga
        .add_step(&ctx, book_hotel, req.clone())
        .with_compensation(cancel_hotel)
        .execute()
        .await?;

    // Manual: the compensation needs the action's result (the charge id).
    let charge = ctx.execute_task(charge_card, req.clone()).await?;
    saga.add_compensation(refund_card, charge.id.clone());

    saga.commit();
    Ok(Confirmation { hotel_id: hotel.id, charge_id: charge.id })
}
```

```typescript
import { Workflow, WorkflowContext, Saga } from '@orcher/sdk';

@Workflow({ name: 'book_trip', version: '1.0.0' })
export class BookTrip {
  async run(ctx: WorkflowContext, req: TripRequest) {
    const saga = new Saga();
    try {
      // Fluent: run the action, register a static compensation.
      const hotel = await saga.addStep(
        () => ctx.executeTask(BookingTasks.bookHotel, req),
        () => ctx.executeTask(BookingTasks.cancelHotel, req),
      );

      // Manual: the compensation needs the action's result (the charge id).
      const charge = await ctx.executeTask(PaymentTasks.charge, req);
      saga.addCompensation(() => ctx.executeTask(PaymentTasks.refund, { chargeId: charge.id }));

      saga.commit();
      return { hotelId: hotel.id, chargeId: charge.id };
    } catch (err) {
      await saga.compensate();
      throw err;
    }
  }
}
```

```python
from orcher import workflow, Saga

@workflow(name="book_trip", version="1.0")
async def book_trip(ctx, req):
    saga = Saga()
    try:
        # Fluent: run the action, register a static compensation.
        hotel = await saga.add_step(
            action=lambda: ctx.execute_task(book_hotel, req=req),
            compensation=lambda: ctx.execute_task(cancel_hotel, req=req),
        )

        # Manual: the compensation needs the action's result (the charge id).
        charge = await ctx.execute_task(charge_card, req=req)
        saga.add_compensation(lambda: ctx.execute_task(refund_card, charge_id=charge["id"]))

        saga.commit()
        return {"hotel_id": hotel["id"], "charge_id": charge["id"]}
    except Exception:
        await saga.compensate()
        raise
```

## Manual compensation

If you want full control — custom ordering, partial rollback, or conditional compensation — write the compensation yourself. Steps execute sequentially, and when one fails, each step's `catch` block undoes the previously completed steps in reverse order. It is more verbose than the helper, but nothing is hidden.

```rust
use orcher::prelude::*;
use anyhow::Result;
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
struct OrderData {
    order_id: String,
    customer_id: String,
    amount: f64,
    items: Vec<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
struct OrderResult {
    order_id: String,
    success: bool,
    payment_id: Option<String>,
    inventory_id: Option<String>,
    shipment_id: Option<String>,
}

// Basic saga workflow with compensation
#[workflow(name = "order_saga", version = "1.0.0")]
pub async fn order_saga(
    ctx: WorkflowContext,
    order: OrderData,
) -> Result<OrderResult> {
    println!("Starting order saga for {}", order.order_id);

    let mut result = OrderResult {
        order_id: order.order_id.clone(),
        success: false,
        payment_id: None,
        inventory_id: None,
        shipment_id: None,
    };

    // Step 1: Reserve inventory
    let inventory_id = match ctx
        .execute_task(reserve_inventory, order.items.clone())
        .await
    {
        Ok(id) => {
            result.inventory_id = Some(id.clone());
            id
        }
        Err(e) => {
            println!("Inventory reservation failed: {}", e);
            return Ok(result);
        }
    };

    // Step 2: Charge payment
    let payment_id = match ctx
        .execute_task(charge_payment, order.amount)
        .await
    {
        Ok(id) => {
            result.payment_id = Some(id.clone());
            id
        }
        Err(e) => {
            println!("Payment failed, compensating inventory");
            // Compensate: Release inventory
            ctx.execute_task(release_inventory, inventory_id).await?;
            return Ok(result);
        }
    };

    // Step 3: Create shipment
    let shipment_id = match ctx
        .execute_task(create_shipment, order.order_id.clone())
        .await
    {
        Ok(id) => {
            result.shipment_id = Some(id.clone());
            id
        }
        Err(e) => {
            println!("Shipment failed, compensating payment and inventory");
            // Compensate: Refund payment
            ctx.execute_task(refund_payment, payment_id).await?;
            // Compensate: Release inventory
            ctx.execute_task(release_inventory, inventory_id).await?;
            return Ok(result);
        }
    };

    result.success = true;
    println!("Order saga completed successfully");
    Ok(result)
}
```

```typescript
import {
  Workflow, Tasks, Task, WorkflowContext, TaskContext, createTaskRefs
} from '@orcher/sdk';

interface OrderData {
  orderId: string;
  customerId: string;
  amount: number;
  items: string[];
}

interface OrderResult {
  orderId: string;
  success: boolean;
  paymentId?: string;
  inventoryId?: string;
  shipmentId?: string;
}

@Tasks()
class OrderSagaTasks {
  @Task({ name: 'reserveInventory' })
  async reserveInventory(ctx: TaskContext, items: string[]): Promise<string> { /* ... */ }

  @Task({ name: 'releaseInventory' })
  async releaseInventory(ctx: TaskContext, inventoryId: string): Promise<void> { /* ... */ }

  @Task({ name: 'chargePayment' })
  async chargePayment(ctx: TaskContext, amount: number): Promise<string> { /* ... */ }

  @Task({ name: 'refundPayment' })
  async refundPayment(ctx: TaskContext, paymentId: string): Promise<void> { /* ... */ }

  @Task({ name: 'createShipment' })
  async createShipment(ctx: TaskContext, orderId: string): Promise<string> { /* ... */ }
}

const tasks = createTaskRefs(OrderSagaTasks);

// Basic saga workflow with compensation
@Workflow()
class OrderSaga {
  async execute(ctx: WorkflowContext, order: OrderData): Promise<OrderResult> {
    console.log(`Starting order saga for ${order.orderId}`);

    const result: OrderResult = {
      orderId: order.orderId,
      success: false,
    };

    // Step 1: Reserve inventory
    let inventoryId: string;
    try {
      inventoryId = await ctx.executeTask(tasks.reserveInventory, order.items);
      result.inventoryId = inventoryId;
    } catch (e) {
      console.log('Inventory reservation failed:', e);
      return result;
    }

    // Step 2: Charge payment
    let paymentId: string;
    try {
      paymentId = await ctx.executeTask(tasks.chargePayment, order.amount);
      result.paymentId = paymentId;
    } catch (e) {
      console.log('Payment failed, compensating inventory');
      // Compensate: Release inventory
      await ctx.executeTask(tasks.releaseInventory, inventoryId);
      return result;
    }

    // Step 3: Create shipment
    try {
      const shipmentId = await ctx.executeTask(tasks.createShipment, order.orderId);
      result.shipmentId = shipmentId;
    } catch (e) {
      console.log('Shipment failed, compensating payment and inventory');
      // Compensate: Refund payment
      await ctx.executeTask(tasks.refundPayment, paymentId);
      // Compensate: Release inventory
      await ctx.executeTask(tasks.releaseInventory, inventoryId);
      return result;
    }

    result.success = true;
    console.log('Order saga completed successfully');
    return result;
  }
}
```
