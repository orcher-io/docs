Complete reference documentation for the **Orcher CLI** (`orcher`). Manage workflows, namespaces, queues, and server processes from your terminal.

## Installation

### Using Cargo

```bash
cargo install orcher-cli
```

### Verify Installation

```bash
orcher --version
```

---

## Quick Start

```bash
# Create a new project
orcher new project my-app

# Configure a server context
orcher config set-context local --server http://localhost:8080

# Start the server
orcher server start --foreground

# Run a workflow
orcher run my-workflow --param order_id=123
```

## Global Flags

These flags apply to all commands:

| Flag | Environment Variable | Default | Description |
|------|----------------------|---------|-------------|
| `--config` | `ORCHER_CONFIG` | `~/.orcher/config.yaml` | Config file path |
| `--context` | `ORCHER_CONTEXT` | `local` | Context to use |
| `-n, --namespace` | `ORCHER_NAMESPACE` | `default` | Namespace |
| `-o, --output` | — | `table` | Output format: table, json, yaml, name, wide |
| `-v, --verbose` | `ORCHER_VERBOSE` | `false` | Enable debug logging |
| `-q, --quiet` | `ORCHER_QUIET` | `false` | Suppress non-essential output |
| `--no-color` | `NO_COLOR` | `false` | Disable colored output |
| `--server` | `ORCHER_SERVER` | — | Override server URL |
| `--api-url` | `ORCHER_API_URL` | `--server` host on port `8080` | REST API address (the engine's HTTP port) |
| `--redis-url` | `ORCHER_REDIS_URL` | — | Redis URL for DLQ operations |
