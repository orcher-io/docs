The ORCHER TypeScript SDK (`@orcher/sdk`) lets you write workflows and tasks as plain async
TypeScript. It offers two ways to define them, and you can mix them in one worker:

- **Functional**: `task({ ... })` and `workflow({ ... })` return typed references, with no classes.
- **Decorators**: `@Tasks()`/`@Task()` on a class whose constructor dependencies are injected,
  and `@Workflow({ name })` on a class with a `run()` method.

Both register what they define in the process when the module is imported, and a worker
started in that process serves everything registered. Task references carry their input and
output types, so `ctx.executeTask()` is checked by the compiler.

---

## Installation

```bash
npm install @orcher/sdk
```

### Requirements

- **Node.js 22 or later.**
- **A supported platform.** The SDK runs on a native core, shipped prebuilt for macOS (arm64
  and x64) and Linux (x64 and arm64, with glibc or musl). npm installs the one that matches
  your machine. Windows is not supported.
- **Legacy decorators.** The decorators need `experimentalDecorators`, and constructor
  injection needs `emitDecoratorMetadata`:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "commonjs",
    "strict": true,
    "experimentalDecorators": true,
    "emitDecoratorMetadata": true
  }
}
```
