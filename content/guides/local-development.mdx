Develop and test workflows locally before deploying to production.

## Prerequisites

- **PostgreSQL 14+** — Workflow state and journals
- **Redis 7+** — Task dispatch queues
- **Rust 1.70+** / **Python 3.10+** / **Node.js 18+** — Depending on your SDK

## Quickstart

1. Get the quickstart, which runs the engine image with Docker Compose:

   ```bash
   git clone https://github.com/orcher-io/quickstart.git
   cd quickstart
   ```

2. Start dependencies:

   ```bash
   docker-compose up -d postgres redis
   ```

3. Run the orchestrator:

   ```bash
   cargo run -p orchestrator -- --config services/orchestrator/config/development.toml
   ```

4. Run your worker:

   ```bash
   # Rust
   cargo run -p my-workflow-worker

   # TypeScript
   npx ts-node worker.ts

   # Python
   python worker.py
   ```
