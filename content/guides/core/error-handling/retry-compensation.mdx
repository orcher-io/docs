## Automatic Retry

When a task fails due to a transient error — such as a network timeout, a temporary service outage, or a rate limit — Orcher can automatically retry it according to a configurable retry policy. You specify the maximum number of attempts, the delay bounds (initial and max interval), and a backoff coefficient that grows the delay exponentially (set it to `1.0` for fixed-interval retries). Inside the task, you can use `ctx.attempt()` to check which attempt you're on and `ctx.is_retry()` / `ctx.isRetry()` to detect whether this is a retry execution.

```rust
use orcher::prelude::*;
use anyhow::Result;

// Simple retry with exponential backoff
#[task(
  name = "fetch_data",
  retry = 5  // Retry up to 5 times
)]
pub async fn fetch_data(
  ctx: TaskContext,
  url: String,
) -> Result<ApiResponse> {
  if ctx.is_retry() {
    tracing::warn!("Retrying fetch (attempt {})", ctx.attempt());
  }

  let response = reqwest::get(&url)
    .await
    .context("Failed to fetch data")?;

  if response.status().is_server_error() {
    // 5xx errors will trigger retry
    return Err(anyhow::anyhow!("Server error: {}", response.status()));
  }

  let data = response.json().await?;
  Ok(data)
}

// Advanced retry policy
#[task(
  name = "critical_operation",
  retry_policy(
    max_attempts = 5,
    initial_interval = 1,       // 1 second
    max_interval = 60,          // Cap at 60 seconds
    backoff_coefficient = 2.0   // Double each time (1.0 = fixed intervals)
  )
)]
pub async fn critical_operation(
  _ctx: TaskContext,
  input: OperationInput,
) -> Result<OperationResult> {
  // Retry delays: 1s, 2s, 4s, 8s, 16s
  external_service::call(input).await
}
```

### Retry Backoff

Orcher computes the delay between retry attempts with exponential backoff: each delay is the previous one multiplied by `backoff_coefficient`, starting from `initial_interval` and capped at `max_interval`. A coefficient of `2.0` doubles the delay each time; a coefficient of `1.0` keeps the interval fixed. Exponential backoff (coefficient > 1.0) is recommended for most external service calls, while a fixed interval (coefficient = 1.0) works well for predictable transient failures.

## Compensation (Saga Pattern)

The Saga pattern provides a way to maintain data consistency across multiple steps without distributed transactions. Each forward step is paired with a compensation action that undoes its effect. When a later step fails, you run the compensations for the completed steps in reverse order — your own logic, made durable by Orcher. Done consistently, this keeps the system from being stuck partially committed: either every step succeeds, or the completed ones are undone.

```rust
use orcher::prelude::*;
use anyhow::Result;

#[workflow(name = "booking_saga", version = "1.0.0")]
pub async fn booking_saga(
  ctx: WorkflowContext,
  input: BookingInput,
) -> Result<BookingResult> {
  // Step 1: Book hotel
  let hotel_booking = match ctx
    .execute_task(book_hotel, input.hotel.clone())
    .await
  {
    Ok(booking) => booking,
    Err(e) => {
      // First step failed, no compensation needed
      return Err(anyhow::anyhow!("Hotel booking failed: {}", e));
    }
  };

  // Step 2: Book flight
  let flight_booking = match ctx
    .execute_task(book_flight, input.flight.clone())
    .await
  {
    Ok(booking) => booking,
    Err(e) => {
      // Compensate: Cancel hotel
      tracing::error!("Flight booking failed, canceling hotel");
      let _ = ctx
        .execute_task(cancel_hotel, hotel_booking.id)
        .await;

      return Err(anyhow::anyhow!("Flight booking failed: {}", e));
    }
  };

  // Step 3: Book car rental
  let car_booking = match ctx
    .execute_task(book_car, input.car.clone())
    .await
  {
    Ok(booking) => booking,
    Err(e) => {
      // Compensate: Cancel flight and hotel (reverse order)
      tracing::error!("Car booking failed, canceling flight and hotel");

      let _ = ctx
        .execute_task(cancel_flight, flight_booking.id)
        .await;

      let _ = ctx
        .execute_task(cancel_hotel, hotel_booking.id)
        .await;

      return Err(anyhow::anyhow!("Car booking failed: {}", e));
    }
  };

  Ok(BookingResult {
    hotel: hotel_booking,
    flight: flight_booking,
    car: car_booking,
    status: "completed".to_string(),
  })
}
```

```typescript
import { Workflow, Tasks, Task, WorkflowContext, createTaskRefs } from '@orcher/sdk';

@Tasks()
class BookingTasks {
  @Task({ name: 'bookHotel' })
  async bookHotel(ctx: TaskContext, input: HotelInput): Promise<HotelBooking> { /* ... */ }

  @Task({ name: 'bookFlight' })
  async bookFlight(ctx: TaskContext, input: FlightInput): Promise<FlightBooking> { /* ... */ }

  @Task({ name: 'bookCar' })
  async bookCar(ctx: TaskContext, input: CarInput): Promise<CarBooking> { /* ... */ }

  @Task({ name: 'cancelHotel' })
  async cancelHotel(ctx: TaskContext, bookingId: string): Promise<void> { /* ... */ }

  @Task({ name: 'cancelFlight' })
  async cancelFlight(ctx: TaskContext, bookingId: string): Promise<void> { /* ... */ }
}

const tasks = createTaskRefs(BookingTasks);

@Workflow()
class BookingSaga {
  async execute(ctx: WorkflowContext, input: BookingInput): Promise<BookingResult> {
    // Step 1: Book hotel
    let hotelBooking: HotelBooking;
    try {
      hotelBooking = await ctx.executeTask(tasks.bookHotel, input.hotel);
    } catch (e) {
      // First step failed, no compensation needed
      throw new Error(`Hotel booking failed: ${e}`);
    }

    // Step 2: Book flight
    let flightBooking: FlightBooking;
    try {
      flightBooking = await ctx.executeTask(tasks.bookFlight, input.flight);
    } catch (e) {
      // Compensate: Cancel hotel
      console.error('Flight booking failed, canceling hotel');
      await ctx.executeTask(tasks.cancelHotel, hotelBooking.id);

      throw new Error(`Flight booking failed: ${e}`);
    }

    // Step 3: Book car rental
    let carBooking: CarBooking;
    try {
      carBooking = await ctx.executeTask(tasks.bookCar, input.car);
    } catch (e) {
      // Compensate: Cancel flight and hotel (reverse order)
      console.error('Car booking failed, canceling flight and hotel');

      await ctx.executeTask(tasks.cancelFlight, flightBooking.id);
      await ctx.executeTask(tasks.cancelHotel, hotelBooking.id);

      throw new Error(`Car booking failed: ${e}`);
    }

    return {
      hotel: hotelBooking,
      flight: flightBooking,
      car: carBooking,
      status: 'completed',
    };
  }
}
```

from orcher import workflow, WorkflowContext

@workflow(name="booking_saga", version="1.0.0")
async def booking_saga(ctx: WorkflowContext, input: dict) -> dict:
  # Step 1: Book hotel
  try:
    hotel_booking = await ctx.execute_task(book_hotel, input["hotel"])
  except Exception as e:
    # First step failed, no compensation needed
    raise Exception(f"Hotel booking failed: {e}")

  # Step 2: Book flight
  try:
    flight_booking = await ctx.execute_task(book_flight, input["flight"])
  except Exception as e:
    # Compensate: Cancel hotel
    print("Flight booking failed, canceling hotel")
    await ctx.execute_task(cancel_hotel, hotel_booking["id"])

    raise Exception(f"Flight booking failed: {e}")

  # Step 3: Book car rental
  try:
    car_booking = await ctx.execute_task(book_car, input["car"])

    print("Car booking failed, canceling flight and hotel")

    await ctx.execute_task(cancel_flight, flight_booking["id"])

    raise Exception(f"Car booking failed: {e}")

  return {
    "hotel": hotel_booking,
    "flight": flight_booking,
    "car": car_booking,
