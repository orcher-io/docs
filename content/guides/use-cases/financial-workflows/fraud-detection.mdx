For high-value transactions, you need a fraud detection pipeline that auto-approves low-risk payments, auto-rejects high-risk ones, and routes medium-risk transactions to a human reviewer with a configurable timeout. Orcher's `wait_for_event_with_timeout` makes the human-in-the-loop step trivial — the workflow pauses until a reviewer signals approval or the timeout expires.

## How it works

One risk assessment, three routes. The two automatic routes finish in milliseconds; the third parks the workflow in front of a human — and only that route pays any waiting cost.

```rust
use orcher::prelude::*;
use anyhow::Result;
use std::time::Duration;

#[derive(Debug, Clone, Serialize, Deserialize)]
enum RiskLevel { Low, Medium, High }

#[derive(Debug, Clone, Serialize, Deserialize)]
struct FraudScore {
    risk_level: RiskLevel,
    score: f64,
    reasons: Vec<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
struct ReviewDecision {
    approved: bool,
    reviewer: String,
    notes: String,
}

#[task]
async fn assess_fraud_risk(input: PaymentInput) -> Result<FraudScore> {
    // Call fraud detection service (ML model, rules engine, etc.)
    let score = fraud::assess(&input).await?;
    Ok(score)
}

#[task]
async fn notify_fraud_team(input: PaymentInput, score: FraudScore) -> Result<()> {
    // Send to review queue with all context
    fraud::create_review_case(&input, &score).await?;
    Ok(())
}

#[task]
async fn record_fraud_decision(order_id: String, approved: bool, reason: String) -> Result<()> {
    audit::log_fraud_decision(&order_id, approved, &reason).await?;
    Ok(())
}

#[workflow(name = "fraud_checked_payment", version = "1.0.0")]
pub async fn fraud_checked_payment(
    ctx: WorkflowContext,
    input: PaymentInput,
) -> Result<PaymentResult> {
    // Step 1: Assess fraud risk
    let fraud_score = ctx.execute_task(assess_fraud_risk, input.clone()).await?;

    match fraud_score.risk_level {
        RiskLevel::Low => {
            // Auto-approve: proceed directly to payment
            ctx.execute_task(record_fraud_decision, (
                input.order_id.clone(), true, "auto-approved: low risk".to_string()
            )).await?;
        }
        RiskLevel::High => {
            // Auto-reject: block the payment
            ctx.execute_task(record_fraud_decision, (
                input.order_id.clone(), false, format!("auto-rejected: {}", fraud_score.reasons.join(", "))
            )).await?;
            anyhow::bail!("Payment rejected: high fraud risk");
        }
        RiskLevel::Medium => {
            // Route to human reviewer
            ctx.execute_task(notify_fraud_team, (input.clone(), fraud_score)).await?;

            // Wait for reviewer decision with 4-hour timeout
            let decision: Option<ReviewDecision> = ctx
                .wait_for_event_with_timeout("fraud_review_decision", Duration::from_secs(14400))
                .await?;

            match decision {
                Some(d) if d.approved => {
                    ctx.execute_task(record_fraud_decision, (
                        input.order_id.clone(), true, format!("approved by {}", d.reviewer)
                    )).await?;
                }
                Some(d) => {
                    ctx.execute_task(record_fraud_decision, (
                        input.order_id.clone(), false, format!("rejected by {}: {}", d.reviewer, d.notes)
                    )).await?;
                    anyhow::bail!("Payment rejected by fraud reviewer");
                }
                None => {
                    // Timeout — auto-reject for safety
                    ctx.execute_task(record_fraud_decision, (
                        input.order_id.clone(), false, "auto-rejected: review timeout".to_string()
                    )).await?;
                    anyhow::bail!("Payment rejected: fraud review timeout");
                }
            }
        }
    }

    // Fraud check passed — proceed to payment
    let result = ctx.execute_task(charge_payment_gateway, (
        input.amount, input.currency.clone(), input.idempotency_key.clone()
    )).await?;

    Ok(PaymentResult {
        charge_id: result.charge_id,
        status: "completed".to_string(),
        order_id: input.order_id,
    })
}
```

```typescript
import { Workflow, Tasks, Task, WorkflowContext, createTaskRefs } from '@orcher/sdk';

type RiskLevel = 'low' | 'medium' | 'high';

interface FraudScore {
  riskLevel: RiskLevel;
  score: number;
  reasons: string[];
}

interface ReviewDecision {
  approved: boolean;
  reviewer: string;
  notes: string;
}

@Tasks()
class FraudTasks {
  @Task()
  async assessFraudRisk(input: PaymentInput): Promise<FraudScore> {
    return await fraud.assess(input);
  }

  @Task()
  async notifyFraudTeam(input: PaymentInput, score: FraudScore): Promise<void> {
    await fraud.createReviewCase(input, score);
  }

  @Task()
  async recordFraudDecision(orderId: string, approved: boolean, reason: string): Promise<void> {
    await audit.logFraudDecision(orderId, approved, reason);
  }
}

const fraudTasks = createTaskRefs(FraudTasks);

@Workflow({ name: 'fraud_checked_payment', version: '1.0.0' })
class FraudCheckedPayment {
  async run(ctx: WorkflowContext, input: PaymentInput): Promise<PaymentResult> {
    const fraudScore = await ctx.executeTask(fraudTasks.assessFraudRisk, input);

    if (fraudScore.riskLevel === 'low') {
      await ctx.executeTask(fraudTasks.recordFraudDecision,
        input.orderId, true, 'auto-approved: low risk');

    } else if (fraudScore.riskLevel === 'high') {
      await ctx.executeTask(fraudTasks.recordFraudDecision,
        input.orderId, false, `auto-rejected: ${fraudScore.reasons.join(', ')}`);
      throw new Error('Payment rejected: high fraud risk');

    } else {
      // Medium risk — route to human reviewer
      await ctx.executeTask(fraudTasks.notifyFraudTeam, input, fraudScore);

      const decision = await ctx.waitForEventWithTimeout<ReviewDecision>(
        'fraud_review_decision', 14400000 // 4 hours
      );

      if (decision?.approved) {
        await ctx.executeTask(fraudTasks.recordFraudDecision,
          input.orderId, true, `approved by ${decision.reviewer}`);
      } else if (decision) {
        await ctx.executeTask(fraudTasks.recordFraudDecision,
          input.orderId, false, `rejected by ${decision.reviewer}: ${decision.notes}`);
        throw new Error('Payment rejected by fraud reviewer');
      } else {
        await ctx.executeTask(fraudTasks.recordFraudDecision,
          input.orderId, false, 'auto-rejected: review timeout');
        throw new Error('Payment rejected: fraud review timeout');
      }
    }

    // Fraud check passed — proceed to payment
    const charge = await ctx.executeTask(
      paymentTasks.chargePaymentGateway,
      input.amount, input.currency, input.idempotencyKey
    );

    return { chargeId: charge.chargeId, status: 'completed', orderId: input.orderId };
  }
}
```

```python
    MEDIUM = "medium"
    HIGH = "high"

class FraudScore:
    risk_level: RiskLevel
    score: float
    reasons: list[str]

@dataclass
class ReviewDecision:
    approved: bool
    reviewer: str
    notes: str

@task
async def assess_fraud_risk(input: PaymentInput) -> FraudScore:
    return await fraud.assess(input)

@task
async def notify_fraud_team(input: PaymentInput, score: FraudScore) -> None:
    await fraud.create_review_case(input, score)

@task
async def record_fraud_decision(order_id: str, approved: bool, reason: str) -> None:
    await audit.log_fraud_decision(order_id, approved, reason)

@workflow(name="fraud_checked_payment", version="1.0.0")
async def fraud_checked_payment(ctx: WorkflowContext, input: PaymentInput) -> PaymentResult:
    fraud_score = await ctx.execute_task(assess_fraud_risk, input)

    if fraud_score.risk_level == RiskLevel.LOW:
        await ctx.execute_task(record_fraud_decision,
            input.order_id, True, "auto-approved: low risk")

    elif fraud_score.risk_level == RiskLevel.HIGH:
        await ctx.execute_task(record_fraud_decision,
            input.order_id, False, f"auto-rejected: {', '.join(fraud_score.reasons)}")
        raise ValueError("Payment rejected: high fraud risk")

    else:
        # Medium risk — route to human reviewer
        await ctx.execute_task(notify_fraud_team, input, fraud_score)

        decision: Optional[ReviewDecision] = await ctx.wait_for_event_with_timeout(
            "fraud_review_decision", timeout=14400  # 4 hours
        )

        if decision and decision.approved:
            await ctx.execute_task(record_fraud_decision,
                input.order_id, True, f"approved by {decision.reviewer}")
        elif decision:
            await ctx.execute_task(record_fraud_decision,
                input.order_id, False, f"rejected by {decision.reviewer}: {decision.notes}")
            raise ValueError("Payment rejected by fraud reviewer")
        else:
            await ctx.execute_task(record_fraud_decision,
                input.order_id, False, "auto-rejected: review timeout")
            raise ValueError("Payment rejected: fraud review timeout")

    # Fraud check passed — proceed to payment
    charge = await ctx.execute_task(
        charge_payment_gateway, input.amount, input.currency, input.idempotency_key
    )

    return PaymentResult(
        charge_id=charge.charge_id,
        status="completed",
        order_id=input.order_id,
```

## The review gate

`wait_for_event_with_timeout` is a race between a human and a clock. The workflow suspends — holding nothing — until either the reviewer's decision arrives as an event or the four-hour deadline fires, and the return value tells you which one won.

Note the ordering: the charge happens *after* the gate. A suspicious transaction waits as an intent, not as captured money — there is nothing to refund if the answer is no. The same suspension mechanics as [durable timers](/guides/use-cases/financial-workflows#waiting-on-the-outside-world) apply: a deploy during the four-hour window changes nothing, and the reviewer's decision wakes the workflow wherever it lands.

## Design notes

- **Timeout must fail safe.** For payments, no answer means *no* — an expired review auto-rejects. If rejection is too costly for your risk profile, escalate instead: re-notify and wait again, but never silently approve.
- **Route the decision back with a correlation ID.** `notify_fraud_team` should include the workflow or order ID in the review case, so the reviewer UI can address its `fraud_review_decision` event to this exact workflow instance. See [Events](/guides/core/events) for the delivery mechanics.
- **Record every decision, on every path.** All five outcomes — auto-approve, auto-reject, human approve, human reject, timeout — pass through `record_fraud_decision` before the workflow acts. Combined with the journal, that's a complete who-decided-what audit trail with no extra logging code.
- **Keep thresholds out of the workflow.** `assess_fraud_risk` returns the risk level; the scoring model and its thresholds live in the fraud service. Tuning them doesn't touch versioned workflow logic — and the journaled score keeps replay deterministic even as the model evolves.
