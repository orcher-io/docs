Actors maintain per-entity state with single-writer guarantees — only one operation runs at a time for a given actor ID, preventing race conditions. Combined with event sourcing, every state change is recorded as an event in the actor's journal. You can rebuild the full state of any entity by replaying its event history, and the journal serves as a complete audit trail.

## How it works

The [overview](/guides/use-cases/event-driven#one-writer-per-entity) showed that same-entity operations serialize. The refinement is that not every operation is a writer: mark the ones that mutate state `exclusive`, and let read-only operations run concurrently. It's a reader/writer lock scoped to one actor ID — but you never write the lock.

```rust
use orcher::prelude::*;
use anyhow::Result;

// Actor: Shopping cart with event-sourced state
#[actor(name = "shopping_cart")]
pub struct ShoppingCart;

#[task]
async fn calculate_shipping(items: Vec<CartItem>) -> Result<f64> {
    shipping_calculator::estimate(items).await
}

#[task]
async fn apply_discount(input: DiscountInput) -> Result<f64> {
    pricing_engine::apply_discount(input.subtotal, &input.code).await
}

#[operations]
impl ShoppingCart {
    #[operation(exclusive)]
    pub async fn add_item(
        ctx: ActorContext,
        item: CartItem,
    ) -> Result<CartState> {
        let mut state = ctx.state().get::<CartState>("cart")
            .await?
            .unwrap_or_default();

        state.items.push(item.clone());
        state.subtotal += item.price * item.quantity as f64;
        state.updated_at = chrono::Utc::now();

        ctx.state().set("cart", &state).await?;
        Ok(state)
    }

    #[operation(exclusive)]
    pub async fn remove_item(
        ctx: ActorContext,
        item_id: String,
    ) -> Result<CartState> {
        let mut state = ctx.state().get::<CartState>("cart")
            .await?
            .unwrap_or_default();

        if let Some(pos) = state.items.iter().position(|i| i.id == item_id) {
            let removed = state.items.remove(pos);
            state.subtotal -= removed.price * removed.quantity as f64;
        }
        state.updated_at = chrono::Utc::now();

        ctx.state().set("cart", &state).await?;
        Ok(state)
    }

    #[operation]
    pub async fn checkout(
        ctx: ActorContext,
        payment: PaymentMethod,
    ) -> Result<CheckoutResult> {
        let state = ctx.state().get::<CartState>("cart")
            .await?
            .unwrap_or_default();

        if state.items.is_empty() {
            return Err(anyhow::anyhow!("Cart is empty"));
        }

        // Calculate shipping (task within actor)
        let shipping = ctx.execute_task(calculate_shipping, state.items.clone()).await?;

        // Start checkout workflow
        let order_id = ctx.start_child_workflow(process_checkout, CheckoutInput {
            items: state.items,
            subtotal: state.subtotal,
            shipping,
            payment,
        }).await?;

        // Clear cart
        ctx.state().set("cart", &CartState::default()).await?;

        Ok(CheckoutResult { order_id })
    }
}
```

```typescript
import {
  Actor,
  Operation,
  Tasks,
  Task,
  ActorContext,
  createTaskRefs,
} from '@orcher/sdk';

@Tasks()
class CartTasks {
  @Task()
  async calculateShipping(items: CartItem[]): Promise<number> {
    return await shippingCalculator.estimate(items);
  }

  @Task()
  async applyDiscount(input: DiscountInput): Promise<number> {
    return await pricingEngine.applyDiscount(input.subtotal, input.code);
  }
}

const tasks = createTaskRefs(CartTasks);

// Actor: Shopping cart with event-sourced state
@Actor({ name: 'shopping_cart' })
class ShoppingCart {
  @Operation({ exclusive: true })
  async addItem(ctx: ActorContext, item: CartItem): Promise<CartState> {
    const state = (await ctx.state().get<CartState>('cart')) ?? {
      items: [], subtotal: 0, updatedAt: new Date(),
    };

    state.items.push(item);
    state.subtotal += item.price * item.quantity;
    state.updatedAt = new Date();

    await ctx.state().set('cart', state);
    return state;
  }

  @Operation({ exclusive: true })
  async removeItem(ctx: ActorContext, itemId: string): Promise<CartState> {
    const state = (await ctx.state().get<CartState>('cart')) ?? {
      items: [], subtotal: 0, updatedAt: new Date(),
    };

    const index = state.items.findIndex((i) => i.id === itemId);
    if (index !== -1) {
      const removed = state.items.splice(index, 1)[0];
      state.subtotal -= removed.price * removed.quantity;
    }
    state.updatedAt = new Date();

    await ctx.state().set('cart', state);
    return state;
  }

  @Operation()
  async checkout(
    ctx: ActorContext,
    payment: PaymentMethod,
  ): Promise<CheckoutResult> {
    const state = (await ctx.state().get<CartState>('cart')) ?? {
      items: [], subtotal: 0, updatedAt: new Date(),
    };

    if (state.items.length === 0) {
      throw new Error('Cart is empty');
    }

    // Calculate shipping (task within actor)
    const shipping = await ctx.executeTask(
      tasks.calculateShipping, state.items,
    );

    // Start checkout workflow
    const orderId = await ctx.startChildWorkflow(ProcessCheckout, {
      items: state.items,
      subtotal: state.subtotal,
      shipping,
      payment,
    });

    // Clear cart
    await ctx.state().set('cart', { items: [], subtotal: 0, updatedAt: new Date() });

    return { orderId };
  }
}
```

from orcher import actor, operation, task, ActorContext

@task
async def calculate_shipping(items: list[CartItem]) -> float:
    return await shipping_calculator.estimate(items)

@task
async def apply_discount(input: DiscountInput) -> float:
    return await pricing_engine.apply_discount(input.subtotal, input.code)

# Actor: Shopping cart with event-sourced state
@actor(name="shopping_cart")
class ShoppingCart:

    @operation(exclusive=True)
    async def add_item(self, ctx: ActorContext, item: CartItem) -> CartState:
        state = await ctx.state().get("cart") or CartState.default()

        state.items.append(item)
        state.subtotal += item.price * item.quantity
        state.updated_at = datetime.utcnow()

        await ctx.state().set("cart", state)
        return state

    @operation(exclusive=True)
    async def remove_item(self, ctx: ActorContext, item_id: str) -> CartState:
        state = await ctx.state().get("cart") or CartState.default()

        for i, item in enumerate(state.items):
            if item.id == item_id:
                removed = state.items.pop(i)
                state.subtotal -= removed.price * removed.quantity
                break
        state.updated_at = datetime.utcnow()

        await ctx.state().set("cart", state)
        return state

    @operation()
    async def checkout(
        self, ctx: ActorContext, payment: PaymentMethod
    ) -> CheckoutResult:
        state = await ctx.state().get("cart") or CartState.default()

        if not state.items:
            raise ValueError("Cart is empty")

        # Calculate shipping (task within actor)
        shipping = await ctx.execute_task(calculate_shipping, state.items)

        # Start checkout workflow
        order_id = await ctx.start_child_workflow(process_checkout, CheckoutInput(
            items=state.items,
            subtotal=state.subtotal,
            shipping=shipping,
            payment=payment,
        ))

        # Clear cart
        await ctx.state().set("cart", CartState.default())

        return CheckoutResult(order_id=order_id)

Each actor instance is identified by a key (e.g., `shopping_cart:user_123`). The `exclusive` flag ensures that `add_item` and `remove_item` operations are serialized — no two exclusive operations run concurrently for the same actor ID, eliminating race conditions on the cart state. Non-exclusive operations like `checkout` can read state concurrently with other non-exclusive operations.

## State is the fold of its events

Event sourcing stores the *changes*, not just the latest snapshot. The current cart is what you get by replaying its events in order — which means the journal isn't only crash recovery, it's the source of truth and a complete audit trail in one.

## Design notes

- **Mutations belong in `exclusive` operations.** Any operation that calls `state().set` is a writer and should be `exclusive` — otherwise it can interleave with another writer and lose an update. Audit each operation by whether it mutates, not by what it's named. (A `checkout` that clears the cart mutates, so it needs the same protection as `add_item`.)
- **Keep exclusive operations short.** An exclusive op holds the actor's writer slot until it returns, so every other write to that entity waits behind it. Do the fast state change in the operation and offload slow work — payment, shipping — to a [child workflow](/guides/use-cases/distributed-systems/child-workflows), exactly as `checkout` starts `process_checkout` rather than charging inline.
- **Snapshot when the history gets long.** Rebuilding from thousands of events is slow. Periodically persist a snapshot of the folded state and replay only the events since — the same journal-growth pressure as a long [scheduled-job loop](/guides/use-cases/background-tasks/scheduled-jobs), solved by checkpointing the fold.
- **Actors partition; they don't parallelize one entity.** Throughput scales with the number of *distinct* actors, because same-ID operations are serial by design. If one entity is a hotspot (a viral product's inventory counter), that single actor is your ceiling — shard it into sub-counters if you must.
