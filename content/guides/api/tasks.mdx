## Task Management

### Submit Task

Submit a task for execution.

```bash
POST /api/v1/tasks
Authorization: Bearer <token>
Content-Type: application/json

{
  "task_type": "send_email",
  "task_queue": "notifications",
  "input": {
    "to": "customer@example.com",
    "subject": "Order Confirmation",
    "body": "Your order has been confirmed."
  },
  "timeout": 60,
  "retry_policy": {
    "max_attempts": 3
  }
}
```

**Response:**

```json
{
  "task_id": "task_xyz123",
  "status": "queued",
  "created_at": "2024-01-07T12:00:00Z"
}
```

### Get Task Status

```bash
GET /api/v1/tasks/:task_id
Authorization: Bearer <token>
```

**Response:**

```json
{
  "task_id": "task_xyz123",
  "task_type": "send_email",
  "status": "completed",
  "result": {
    "message_id": "msg_abc789",
    "sent_at": "2024-01-07T12:00:15Z"
  },
  "started_at": "2024-01-07T12:00:01Z",
  "completed_at": "2024-01-07T12:00:15Z",
  "attempt": 1,
  "duration_ms": 14000
}
```

### Cancel Task

```bash
DELETE /api/v1/tasks/:task_id
Authorization: Bearer <token>
```

**Response:**

```json
{
  "task_id": "task_xyz123",
  "status": "canceled",
  "canceled_at": "2024-01-07T12:00:30Z"
}
```

### List Tasks

```bash
GET /api/v1/tasks?task_type=send_email&status=completed&limit=50
Authorization: Bearer <token>
```

**Response:**

```json
{
  "tasks": [
    {
      "task_id": "task_xyz123",
      "task_type": "send_email",
      "status": "completed",
      "created_at": "2024-01-07T12:00:00Z"
    }
  ],
  "total": 250,
  "limit": 50,
  "offset": 0
}
```
