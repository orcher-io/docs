## Testing Philosophy

When testing workflows, you should focus on:

1. **Unit Tests** - Test workflow logic in isolation with mocked dependencies
2. **Integration Tests** - Test against a real orchestrator with real services
3. **Crash Recovery Tests** - Verify workflows resume correctly after failures
4. **End-to-End Tests** - Test complete user scenarios

**Why test workflows?**

• Catch bugs before production
• Verify durability guarantees
• Ensure idempotency of operations
• Document expected behavior
• Enable confident refactoring

### Basic Unit Test

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use orcher::testing::TestEnv;

    #[tokio::test]
    async fn test_payment_workflow_success() {
        // Create the in-process test environment
        let mut env = TestEnv::new();

        // Register the workflow under test
        env.register_workflow("payment_workflow", payment_workflow);

        // Mock each task the workflow calls
        env.mock_task("charge_card").returns(PaymentResult {
            charge_id: "ch_123".to_string(),
            amount: 99.99,
        });
        env.mock_task("reserve_inventory").returns(InventoryResult {
            reservation_id: "inv_456".to_string(),
        });
        env.mock_task("send_confirmation").returns(NotificationResult {
            message_id: "msg_789".to_string(),
        });

        // Execute the workflow
        let input = PaymentInput {
            order_id: "ord_123".to_string(),
            amount: 99.99,
            card_token: "tok_visa".to_string(),
            customer_email: "test@example.com".to_string(),
        };

        let output: PaymentOutput = env
            .execute_workflow("payment_workflow", input)
            .await
            .unwrap();

        // Assert success
        assert_eq!(output.charge_id, "ch_123");
        env.assert_task_called("charge_card", 1);
    }
}
```

### Testing Error Scenarios

```rust
#[tokio::test]
async fn test_payment_workflow_payment_failure() {
    let mut env = TestEnv::new();
    env.register_workflow("payment_workflow", payment_workflow);

    // Mock a payment failure
    env.mock_task("charge_card").fails_with("Card declined");

    let input = PaymentInput {
        order_id: "ord_123".to_string(),
        amount: 99.99,
        card_token: "tok_declined".to_string(),
        customer_email: "test@example.com".to_string(),
    };

    let result: orcher::Result<PaymentOutput> =
        env.execute_workflow("payment_workflow", input).await;

    // Assert failure
    assert!(result.is_err());
    assert!(result.unwrap_err().to_string().contains("Card declined"));
}
```

### Setup Test Environment

```rust
// tests/integration_test.rs
use orcher::{Client, Worker, WorkerBuilder};
use testcontainers::{clients, images};

struct TestEnv {
    client: Client,
    _worker: Worker,
    _orchestrator: Container,
}

async fn setup_test_env() -> TestEnv {
    // Start Orcher orchestrator container
    let docker = clients::Cli::default();
    let orchestrator = docker.run(images::generic::GenericImage::new(
        "orcherapp/orcher",
        "latest"
    ));
    
    let orchestrator_url = format!(
        "http://localhost:{}",
        orchestrator.get_host_port_ipv4(8080)
    );
    
    // Start worker with test workflows.
    // Workflows and tasks are auto-registered from the #[workflow]/#[task] macros.
    let worker = WorkerBuilder::new()
        .server_url(&orchestrator_url)
        .task_queue("default")
        .build()
        .await
        .unwrap();
    
    tokio::spawn(async move {
        worker.run().await
    });
    
    // Create client
    let client = Client::connect(&orchestrator_url).await.unwrap();
    
    // Wait for worker to be ready
    tokio::time::sleep(tokio::time::Duration::from_secs(2)).await;
    
    TestEnv {
        client,
        _worker: worker,
        _orchestrator: orchestrator,
    }
}

#[tokio::test]
async fn test_payment_workflow_integration() {
    let env = setup_test_env().await;
    
    // Start workflow
    let handle = env.client
        .start_workflow("payment_workflow", PaymentInput {
            order_id: "ord_integration_123".to_string(),
            amount: 99.99,
            card_token: "tok_visa".to_string(),
            customer_email: "integration@example.com".to_string(),
        })
        .await
        .unwrap();
    
    // Wait for result
    let result: PaymentOutput = handle.result().await.unwrap();
    
    // Assert
    assert_eq!(result.status, "completed");
    assert!(result.charge_id.starts_with("ch_"));
}
```

### Testing with Mock Services

```rust
use wiremock::{MockServer, Mock, ResponseTemplate};
use wiremock::matchers::{method, path};

#[tokio::test]
async fn test_with_mock_external_api() {
    // Start mock HTTP server
    let mock_server = MockServer::start().await;
    
    // Mock Stripe API
    Mock::given(method("POST"))
        .and(path("/v1/charges"))
        .respond_with(ResponseTemplate::new(200)
            .set_body_json(json!({
                "id": "ch_mock_123",
                "amount": 9999,
                "currency": "usd",
                "status": "succeeded"
            })))
        .mount(&mock_server)
        .await;
    
    // Configure workflow to use mock server
    std::env::set_var("STRIPE_API_URL", mock_server.uri());
    
    let env = setup_test_env().await;
    
    // Run workflow
    let handle = env.client
        .start_workflow("payment_workflow", PaymentInput {
            order_id: "ord_mock_123".to_string(),
            amount: 99.99,
            card_token: "tok_visa".to_string(),
            customer_email: "mock@example.com".to_string(),
        })
        .await
        .unwrap();
    
    let result: PaymentOutput = handle.result().await.unwrap();
    assert_eq!(result.charge_id, "ch_mock_123");
}
```

## Crash Recovery Testing

Test that workflows resume correctly after crashes.

<Tabs
  scrollable
  size="small"
  type="underlined"
  defaultActiveId="rust"
  queryGroup="sdk"
>

<TabPanel id="rust" label="Rust">

### Simulated Crash Test

```rust
#[tokio::test]
async fn test_workflow_survives_crash() {
    let env = setup_test_env().await;
    
    // Start workflow
    let handle = env.client
        .start_workflow("payment_workflow", PaymentInput {
            order_id: "ord_crash_test".to_string(),
            amount: 99.99,
            card_token: "tok_visa".to_string(),
            customer_email: "crash@example.com".to_string(),
        })
        .await
        .unwrap();
    
    // Wait for first step to complete
    tokio::time::sleep(tokio::time::Duration::from_millis(100)).await;
    
    // Simulate crash by killing worker (shutdown() is synchronous)
    env._worker.shutdown();
    
    // Wait a moment
    tokio::time::sleep(tokio::time::Duration::from_secs(1)).await;
    
    // Restart worker (workflows/tasks are auto-registered from the macros)
    let new_worker = WorkerBuilder::new()
        .server_url(&env.orchestrator_url)
        .task_queue("default")
        .build()
        .await
        .unwrap();
    
    tokio::spawn(async move {
        new_worker.run().await
    });
    
    // Wait for workflow to resume and complete
    let result: PaymentOutput = handle.result().await.unwrap();
    
    // Verify workflow completed successfully
    assert_eq!(result.status, "completed");
}
```

### Verify No Duplicate Operations

```rust
use std::sync::{Arc, Mutex};

#[tokio::test]
async fn test_no_duplicate_charges() {
    // Track API calls
    let call_count = Arc::new(Mutex::new(0));
    let call_count_clone = call_count.clone();
    
    // Mock server that counts calls
    let mock_server = MockServer::start().await;
    Mock::given(method("POST"))
        .and(path("/v1/charges"))
        .respond_with(move |_req: &wiremock::Request| {
            let mut count = call_count_clone.lock().unwrap();
            *count += 1;
            
            ResponseTemplate::new(200).set_body_json(json!({
                "id": "ch_123",
                "amount": 9999,
                "status": "succeeded"
            }))
        })
        .mount(&mock_server)
        .await;
    
    std::env::set_var("STRIPE_API_URL", mock_server.uri());
    
    let env = setup_test_env().await;
    
    // Start workflow
    let handle = env.client
        .start_workflow("payment_workflow", PaymentInput {
            order_id: "ord_no_dup".to_string(),
            amount: 99.99,
            card_token: "tok_visa".to_string(),
            customer_email: "nodup@example.com".to_string(),
        })
        .await
        .unwrap();
    
    // Simulate crash and restart (shutdown() is synchronous)
    tokio::time::sleep(tokio::time::Duration::from_millis(100)).await;
    env._worker.shutdown();
    
    let new_worker = restart_worker(&env).await;
    
    // Wait for completion
    let _result: PaymentOutput = handle.result().await.unwrap();
    
    // Verify API was called exactly once
    let final_count = *call_count.lock().unwrap();
    assert_eq!(final_count, 1, "Stripe API should be called exactly once");
}
```

### Testing Replay from Journal

```rust
#[tokio::test]
async fn test_replay_from_journal() {
    let env = setup_test_env().await;
    
    // Start workflow and wait for first step
    let handle = env.client
        .start_workflow("multi_step_workflow", MultiStepInput {
            steps: vec!["step1", "step2", "step3"],
        })
        .await
        .unwrap();
    
    // Wait for step 1 to complete
    tokio::time::sleep(tokio::time::Duration::from_millis(200)).await;
    
    // Check journal has step 1
    let journal = env.client
        .get_workflow_journal(handle.id())
        .await
        .unwrap();
    assert_eq!(journal.entries.len(), 1);
    assert_eq!(journal.entries[0].step_name, "step1");
    
    // Kill worker (shutdown() is synchronous)
    env._worker.shutdown();
    
    // Restart worker
    let _new_worker = restart_worker(&env).await;
    
    // Wait for completion
    let result: MultiStepOutput = handle.result().await.unwrap();
    
    // Verify all steps completed
    assert_eq!(result.completed_steps.len(), 3);
    
    // Check journal has all steps
    let final_journal = env.client
        .get_workflow_journal(handle.id())
        .await
        .unwrap();
    assert_eq!(final_journal.entries.len(), 3);
}
```

### Running Example Tests

```bash
git clone https://github.com/orcher-io/sdk-rust
cd sdk-rust

# Run the durable_execution example's tests, which need no engine
cargo test -p orcher-example-durable-execution

# Run it against a local engine: a worker and a client in one process
cargo run -p orcher-example-durable-execution -- --e2e
```

### Adapting Examples to Your Needs

`examples/durable_execution/src/workflows/payment.rs` is a template for a workflow that calls tasks. Each step is a `#[task]`, and the workflow calls it with `ctx.execute_task`:

```rust
use orcher_sdk::prelude::*;

#[workflow(name = "my_workflow")]
async fn my_workflow(ctx: WorkflowContext, input: MyInput) -> Result<MyOutput> {
    let step1: Step1 = ctx.execute_task(my_step_1, input).await?;
    let step2: Step2 = ctx.execute_task(my_step_2, step1.clone()).await?;
    Ok(MyOutput { step1, step2 })
}
```

Its test runs the workflow in memory with each task mocked, using `TestWorkflowExecutor`; see [Testing](/guides/sdk/rust/testing).

## Testing Best Practices

### 1. Use Descriptive Test Names

```rust
// Bad
#[tokio::test]
async fn test1() { ... }

// Good
#[tokio::test]
async fn test_payment_workflow_succeeds_with_valid_card() { ... }

#[tokio::test]
async fn test_payment_workflow_fails_with_declined_card() { ... }

#[tokio::test]
async fn test_payment_workflow_resumes_after_crash() { ... }
```

### 2. Test Edge Cases

```rust
#[tokio::test]
async fn test_workflow_with_empty_input() { ... }

#[tokio::test]
async fn test_workflow_with_maximum_input_size() { ... }

#[tokio::test]
async fn test_workflow_with_invalid_data() { ... }

#[tokio::test]
async fn test_workflow_timeout() { ... }

#[tokio::test]
async fn test_workflow_cancellation() { ... }
```

### 3. Isolate Tests

```rust
// Use separate database per test
async fn setup_isolated_env(test_name: &str) -> TestEnv {
    let db_name = format!("test_db_{}", test_name);
    
    // Create isolated database
    create_test_database(&db_name).await;
    
    // Start orchestrator with isolated DB
    start_orchestrator_with_db(&db_name).await
}

#[tokio::test]
async fn test_isolated() {
    let env = setup_isolated_env("test_isolated").await;
    // Test runs in complete isolation
}
```

### 4. Clean Up Resources

```rust
#[tokio::test]
async fn test_with_cleanup() {
    let env = setup_test_env().await;
    
    // Test logic
    let result = run_test(&env).await;
    
    // Always cleanup
    cleanup(&env).await;
    
    assert!(result.is_ok());
}

// Or use RAII pattern
impl Drop for TestEnv {
    fn drop(&mut self) {
        // Cleanup automatically
        self.cleanup_sync();
    }
}
```

### 5. Mock External Dependencies

```rust
// Don't make real API calls in tests
#[tokio::test]
async fn test_with_real_stripe() {  // Bad
    // This calls real Stripe API
}

#[tokio::test]
async fn test_with_mock_stripe() {  // Good
    let mock_server = MockServer::start().await;
    // Mock Stripe responses
}
```

## Performance Testing

### Load Testing Workflows

<Tabs
  scrollable
  size="small"
  type="underlined"
  defaultActiveId="rust"
  queryGroup="sdk"
>

<TabPanel id="rust" label="Rust">

```rust
#[tokio::test]
async fn load_test_workflow() {
    let env = setup_test_env().await;
    
    let start = std::time::Instant::now();
    let num_workflows = 1000;
    
    // Start many workflows concurrently
    let handles: Vec<_> = (0..num_workflows)
        .map(|i| {
            let client = env.client.clone();
            tokio::spawn(async move {
                client
                    .start_workflow("payment_workflow", PaymentInput {
                        order_id: format!("ord_load_{}", i),
                        amount: 99.99,
                        card_token: "tok_visa".to_string(),
                        customer_email: format!("test{}@example.com", i),
                    })
                    .await
            })
        })
        .collect();
    
    // Wait for all to start
    for handle in handles {
        handle.await.unwrap().unwrap();
    }
    
    let elapsed = start.elapsed();
    let throughput = num_workflows as f64 / elapsed.as_secs_f64();
    
    println!("Started {} workflows in {:?}", num_workflows, elapsed);
    println!("Throughput: {:.2} workflows/sec", throughput);
    
    // Assert reasonable performance
    assert!(throughput > 100.0, "Throughput too low: {}", throughput);
}
```

## Debugging Failed Tests

### Enable Detailed Logging

```bash
# Run tests with full debug logs
RUST_LOG=orcher=debug,my_workflow=trace cargo test -- --nocapture

# Save logs to file
RUST_LOG=debug cargo test 2>&1 | tee test.log
```

### Inspect Test Database

```bash
# Connect to test database
psql postgresql://postgres:postgres@localhost:5432/orcher_test

# View workflow executions
SELECT * FROM workflow_executions WHERE workflow_name = 'payment_workflow';

# View journal entries
SELECT * FROM execution_log WHERE workflow_id = 'wf_abc123';

# View task executions
SELECT * FROM task_executions WHERE workflow_id = 'wf_abc123';
```

### Use Test Helpers

```rust
// Create test helpers for debugging
pub mod test_helpers {
    pub async fn print_workflow_state(client: &Client, workflow_id: &str) {
        let state = client.get_workflow_state(workflow_id).await.unwrap();
        println!("Workflow State: {:#?}", state);
        
        let journal = client.get_workflow_journal(workflow_id).await.unwrap();
        println!("Journal Entries: {:#?}", journal);
    }
}

// Use in tests
#[tokio::test]
async fn test_with_debugging() {
    let env = setup_test_env().await;
    let handle = start_workflow(&env).await;
    
    // Debug workflow state
    test_helpers::print_workflow_state(&env.client, handle.id()).await;
    
    let result = handle.result().await;
    assert!(result.is_ok());
}
```
